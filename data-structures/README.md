# 자료구조 (Data Structures) 학습 기록

**참고 도서**: "Introduction to Algorithms" (CLRS)
**선수과목**: 이산수학, 프로그래밍 기초
**후속과목**: 알고리즘, 운영체제, 데이터베이스

---

## 진도 체크리스트

### Part 1: 기초

- [ ] **알고리즘 분석 기초**
  - 핵심: 시간복잡도, 공간복잡도, Big-O, Big-Ω, Big-Θ
- [ ] **배열 (Array)**
  - 핵심: 정적/동적 배열, 인덱싱, 삽입/삭제 O(n)
- [ ] **연결 리스트 (Linked List)**
  - 핵심: 단일/이중/원형, 삽입/삭제 O(1), 탐색 O(n)

### Part 2: 스택과 큐

- [ ] **스택 (Stack)**
  - 핵심: LIFO, push/pop, 활용 (괄호 검사, 후위표기)
- [ ] **큐 (Queue)**
  - 핵심: FIFO, enqueue/dequeue, 원형 큐
- [ ] **덱 (Deque)**
  - 핵심: 양방향 삽입/삭제
- [ ] **우선순위 큐**
  - 핵심: 힙 기반 구현, O(log n)

### Part 3: 트리 (Tree)

- [ ] **트리 기초**
  - 핵심: 노드, 엣지, 루트, 리프, 높이, 깊이
- [ ] **이진 트리 (Binary Tree)**
  - 핵심: 전위/중위/후위/레벨 순회
- [ ] **이진 탐색 트리 (BST)**
  - 핵심: 삽입/삭제/탐색, 불균형 문제
- [ ] **균형 이진 트리**
  - 핵심: AVL 트리, 회전 연산
- [ ] **레드-블랙 트리**
  - 핵심: 색상 규칙, 삽입/삭제 재균형
- [ ] **B-트리**
  - 핵심: 다진 트리, 디스크 기반, 데이터베이스 인덱스

### Part 4: 힙 (Heap)

- [ ] **힙 기초**
  - 핵심: 완전 이진 트리, 최대/최소 힙
- [ ] **힙 연산**
  - 핵심: heapify, insert, extract, O(log n)
- [ ] **힙 정렬**
  - 핵심: O(n log n), 제자리 정렬

### Part 5: 해시 (Hash)

- [ ] **해시 테이블 기초**
  - 핵심: 해시 함수, 키-값 저장, O(1) 평균
- [ ] **충돌 해결**
  - 핵심: 체이닝, 개방 주소법 (선형/이차/이중 해싱)
- [ ] **해시 함수 설계**
  - 핵심: 나눗셈법, 곱셈법, 유니버설 해싱

### Part 6: 그래프 (Graph)

- [ ] **그래프 표현**
  - 핵심: 인접 행렬, 인접 리스트, 장단점
- [ ] **그래프 탐색 - BFS**
  - 핵심: 너비 우선 탐색, 큐 사용, 최단 경로
- [ ] **그래프 탐색 - DFS**
  - 핵심: 깊이 우선 탐색, 스택/재귀, 백트래킹
- [ ] **위상 정렬**
  - 핵심: DAG, 선후관계, Kahn's 알고리즘
- [ ] **최소 신장 트리**
  - 핵심: Kruskal, Prim, Union-Find
- [ ] **최단 경로**
  - 핵심: Dijkstra, Bellman-Ford, Floyd-Warshall

### Part 7: 고급 자료구조

- [ ] **트라이 (Trie)**
  - 핵심: 문자열 저장, 접두사 검색
- [ ] **세그먼트 트리**
  - 핵심: 구간 쿼리, 구간 합/최솟값
- [ ] **펜윅 트리 (BIT)**
  - 핵심: 이진 인덱스 트리, 구간 합
- [ ] **유니온-파인드**
  - 핵심: 서로소 집합, 경로 압축, 랭크 합치기
