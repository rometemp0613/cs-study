## 진도 체크리스트

### Part 1: 네트워크 개요

- [ ] **인터넷이란?**
  - 핵심: 프로토콜, 패킷 스위칭, 회선 스위칭
- [ ] **네트워크 구조**
  - 핵심: 엣지, 코어, 접근 네트워크
- [ ] **성능 지표**
  - 핵심: 대역폭, 지연, 손실, 처리량
- [ ] **프로토콜 계층**
  - 핵심: OSI 7계층, TCP/IP 5계층, 캡슐화

### Part 2: 애플리케이션 계층

- [ ] **애플리케이션 아키텍처**
  - 핵심: 클라이언트-서버, P2P
- [ ] **HTTP**
  - 핵심: 요청/응답, 메서드, 상태 코드, 쿠키, 캐싱
- [ ] **DNS**
  - 핵심: 도메인 이름, 계층 구조, 레코드 타입
- [ ] **SMTP/POP3/IMAP**
  - 핵심: 이메일 프로토콜
- [ ] **소켓 프로그래밍**
  - 핵심: TCP/UDP 소켓, 클라이언트/서버

### Part 3: 전송 계층

- [ ] **전송 계층 서비스**
  - 핵심: 다중화/역다중화, 포트 번호
- [ ] **UDP**
  - 핵심: 비연결형, 체크섬, 언제 사용?
- [ ] **신뢰적 데이터 전송**
  - 핵심: Stop-and-Wait, 파이프라인
- [ ] **TCP 세그먼트**
  - 핵심: 헤더 구조, 시퀀스/ACK 번호
- [ ] **TCP 연결 관리**
  - 핵심: 3-way 핸드셰이크, 4-way 종료
- [ ] **TCP 흐름 제어**
  - 핵심: 슬라이딩 윈도우, 수신 버퍼
- [ ] **TCP 혼잡 제어**
  - 핵심: AIMD, Slow Start, Fast Recovery

### Part 4: 네트워크 계층 - 데이터 평면

- [ ] **라우터 구조**
  - 핵심: 입력/출력 포트, 스위칭 패브릭
- [ ] **IP 데이터그램**
  - 핵심: IPv4 헤더, 단편화, TTL
- [ ] **IP 주소**
  - 핵심: 클래스, 서브넷, CIDR
- [ ] **NAT**
  - 핵심: 주소 변환, 포트 포워딩
- [ ] **IPv6**
  - 핵심: 헤더 형식, 주소 표현
- [ ] **DHCP**
  - 핵심: 동적 주소 할당

### Part 5: 네트워크 계층 - 제어 평면

- [ ] **라우팅 알고리즘**
  - 핵심: 링크 상태, 거리 벡터
- [ ] **OSPF**
  - 핵심: 링크 상태 프로토콜, 영역
- [ ] **BGP**
  - 핵심: 경로 벡터, AS, eBGP/iBGP
- [ ] **SDN**
  - 핵심: OpenFlow, 중앙 제어

### Part 6: 링크 계층

- [ ] **링크 계층 서비스**
  - 핵심: 프레이밍, 오류 검출
- [ ] **다중 접근 프로토콜**
  - 핵심: CSMA/CD, CSMA/CA
- [ ] **MAC 주소**
  - 핵심: 48비트, ARP
- [ ] **이더넷**
  - 핵심: 프레임 구조, 스위치
- [ ] **스위치 vs 라우터**
  - 핵심: L2 vs L3, 포워딩 테이블
- [ ] **VLAN**
  - 핵심: 가상 LAN, 트렁킹

### Part 7: 무선 네트워크

- [ ] **무선 링크 특성**
  - 핵심: 감쇠, 간섭, 숨은 터미널
- [ ] **WiFi (802.11)**
  - 핵심: CSMA/CA, RTS/CTS, 프레임

### Part 8: 네트워크 보안

- [ ] **암호화 기초**
  - 핵심: 대칭키, 공개키, RSA
- [ ] **인증**
  - 핵심: 메시지 무결성, 디지털 서명
- [ ] **TLS/SSL**
  - 핵심: 핸드셰이크, 암호화 통신
- [ ] **방화벽/IDS**
  - 핵심: 패킷 필터링, 상태 기반
