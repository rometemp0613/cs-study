# Claude 지침서

## 프로젝트 개요

이 저장소는 컴퓨터 네트워크(Computer Networks) 학습 프로젝트입니다.
- 참고 도서: "Computer Networking: A Top-Down Approach" (Kurose & Ross)
- 선수과목: 운영체제, 자료구조

## 대화 시작 시 해야 할 일

0. **상위 폴더(study/)의 CLAUDE.md를 먼저 읽고, 변경된 내용이 있는지 확인할 것**
   - 변경 사항이 있으면 이 파일에도 반영

1. **README.md를 읽어서 현재 진도를 파악할 것**
2. 체크리스트에서 완료되지 않은 첫 번째 항목을 확인
3. 사용자에게 다음 공부할 주제를 권유
4. 학습 일지의 마지막 날짜를 확인하여 얼마나 쉬었는지도 언급

## 학습 진행 방식 (상세)

### 1단계: 학습 목표 제시
### 2단계: 동기부여 (실제 인터넷에서 어떻게 동작하는지)
### 3단계: 핵심 개념 설명 (프로토콜 다이어그램!)
### 4단계: 실습 (Wireshark, 소켓 프로그래밍)
### 5단계: 연습 문제
### 6단계: 정리

## 학습 완료 후 할 일

- `notes/` 폴더에 학습 노트 작성
- README.md의 체크리스트 업데이트
- 학습 일지 테이블에 기록 추가

## 학습 마인드셋

- Top-Down 방식: 애플리케이션 → 물리 계층
- 패킷 캡처(Wireshark)로 실제 확인
- 소켓 프로그래밍으로 직접 구현
