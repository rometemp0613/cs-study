## 주제: Ch.5 프로세스 API

### 배운 내용

#### fork() — 프로세스 복제
- 호출한 프로세스의 (거의) 완전한 복사본 생성
- **호출 1번, 리턴 2번**: 부모 → 자식PID(양수), 자식 → 0, 실패 → 음수
- fork() 후 누가 먼저 실행될지는 비결정적 (CPU 스케줄러가 결정)

#### wait() — 자식 기다리기
- 부모가 호출하면 자식이 종료될 때까지 블록
- 비결정적 → 결정적으로 만듦
- waitpid(): 특정 자식 PID 지정해서 기다리기

#### exec() — 프로그램 변신
- 현재 프로세스의 코드/데이터/힙/스택을 새 프로그램으로 덮어씀
- 새 프로세스를 만드는 게 아님, 성공하면 절대 리턴 안 함
- 6가지 변형: execl, execlp, execle, execv, execvp, execvpe

#### fork()+exec() 분리의 핵심 — 셸의 비밀
- fork()와 exec() 사이의 틈에서 fd를 조작할 수 있음
- 리다이렉션: close(stdout) → open(파일) → exec()
- 파이프: pipe() 시스템 콜로 프로세스 간 출력→입력 연결

#### 프로세스 제어와 사용자
- kill(): 프로세스에 시그널 전송 (종료뿐 아니라 다양한 시그널)
- SIGINT(Ctrl+C): 종료 / SIGTSTP(Ctrl+Z): 일시 중지
- 일반 사용자: 자기 프로세스만 / root: 모든 프로세스 제어
