### 배운 내용

- **OS의 3대 주제**: 가상화(Virtualization), 동시성(Concurrency), 영속성(Persistence)

## 주제 2: Ch.4 프로세스

### 배운 내용

- **프로세스**: 실행 중인 프로그램. OS가 제공하는 가장 기본적인 추상화
- **머신 상태**: 메모리(주소 공간), 레지스터(PC, SP 등), I/O 정보(열린 파일 목록)
- **프로세스 상태 전이**:
  - Running (실행 중) → Ready (대기) → Blocked (I/O 대기)
  - Running ↔ Ready: 스케줄링에 의해
  - Running → Blocked: I/O 요청 시
  - Blocked → Ready: I/O 완료 시
- **PCB (Process Control Block)**: OS가 프로세스 정보를 저장하는 자료구조 (pid, state, context, 파일 등)
- **메커니즘 vs 정책**: HOW(컨텍스트 스위칭) vs WHICH(스케줄링 알고리즘). 분리하면 정책만 교체 가능
- **프로세스 API 5가지**: Create, Destroy, Wait, Misc Control, Status
