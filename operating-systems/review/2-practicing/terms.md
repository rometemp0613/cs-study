# 복습 중인 용어/개념

## Ch.2 운영체제 소개

- **동시성 (Concurrency)**: 여러 작업이 동시에 실행될 때 발생하는 문제들. counter++가 3개 명령어(load→increment→store)로 이루어져 원자적이지 않아서 경쟁 조건 발생
- **OS의 설계 목표**: 추상화(편의성) / 고성능(오버헤드 최소화) / 보호·격리(프로세스 간 간섭 방지) / 신뢰성(OS 멈추면 전체 멈춤)
- **멀티프로그래밍 (Multiprogramming)**: 여러 프로그램을 메모리에 올려놓고 I/O 대기 시 다른 프로그램 실행하여 CPU 활용도 향상
- **시분할 (Time Sharing)**: CPU를 시간적으로 쪼개서 번갈아 사용하는 기법
- **가상화 (Virtualization)**: 물리 자원(CPU, 메모리, 디스크)을 가상 형태로 변환하여 각 프로세스에게 전용 자원이 있는 것처럼 보이게 하는 기법
- **시스템 콜 (System Call)**: 유저 모드에서 커널 모드로 전환하여 OS 기능을 요청하는 인터페이스. 일반 함수 호출과 달리 하드웨어 권한 수준이 상승(trap)
- **배치 처리 (Batch Processing)**: 초기 OS 방식. 한 번에 한 프로그램만 실행, 운영자가 순서 결정

## Ch.4 프로세스

- **상태 전이 주체**: Running→Blocked: 프로세스 자신(I/O 요청) / Blocked→Ready: 하드웨어(인터럽트) / Ready→Running: OS 스케줄러 / Running→Ready: OS 스케줄러(시간 할당량 소진)
- **유저 모드 / 커널 모드**: 유저 모드에서는 I/O 직접 접근 불가, 시스템 콜로 trap하면 커널 모드로 전환되어 OS가 하드웨어에 완전한 접근 가능. return-from-trap으로 복귀
- **Context (레지스터 컨텍스트)**: 프로세스 정지 시 레지스터 값을 PCB에 저장하고, 재개 시 복원하여 이어서 실행 (컨텍스트 스위칭의 핵심)
- **PC (Program Counter)**: 다음에 실행할 명령어의 주소를 가리키는 레지스터. IP(Instruction Pointer)라고도 함
- **주소 공간 (Address Space)**: 프로세스가 접근 가능한 메모리 영역. 코드 + 정적 데이터 + 힙 + 스택으로 구성
- **머신 상태 (Machine State)**: 프로세스를 구성하는 요소들 — 메모리(주소 공간), 레지스터(PC, SP 등), I/O 정보(열린 파일 목록)
- **프로세스 (Process)**: 실행 중인 프로그램. 프로그램(디스크에 있는 정적 코드)과 다름
- **Lazy Loading**: 현대 OS는 프로그램 전체를 한번에 로딩하지 않고, 필요한 부분만 그때그때 로딩 (페이징/스와핑과 연관)
- **Blocked→Running 직접 불가**: I/O 완료 시 Ready로 가서 줄 서야 함. 다른 프로세스가 CPU 사용 중일 수 있으므로
- **PCB (Process Control Block)**: OS가 각 프로세스 정보를 저장하는 자료구조. pid, state, context(레지스터), 열린 파일, 메모리 정보 등 포함
- **Zombie 상태**: 프로세스가 종료했지만 부모가 wait()로 종료 코드를 아직 회수하지 않은 상태. 부모가 wait() 호출해야 완전히 정리됨
- **공간 분할 (Space Sharing)**: 자원을 공간적으로 나눠 사용하는 기법 (예: 디스크 블록)
- **메커니즘 vs 정책**: 메커니즘(Mechanism) = HOW(예: 컨텍스트 스위칭) / 정책(Policy) = WHICH(예: 스케줄링 알고리즘). 분리하면 정책만 교체 가능
- **영속성 (Persistence)**: 파일 시스템과 I/O 장치를 통해 데이터를 전원이 꺼져도 안전하게 저장하는 것. CPU/메모리와 달리 디스크는 가상화하지 않고 공유함
- **프로세스 로딩 순서**: (1) 코드+정적 데이터를 디스크→메모리 로딩 (2) 스택 할당(argc/argv 초기화) (3) 힙 할당 (4) I/O 설정(fd 0,1,2) (5) main()으로 점프
- **프로세스 상태 3가지**: Running(CPU에서 실행 중) / Ready(실행 준비 완료, 스케줄링 대기) / Blocked(I/O 대기 중, CPU 사용 불가)
- **프로세스 API 5가지**: Create(생성) / Destroy(강제 종료) / Wait(대기) / Miscellaneous Control(일시 중지/재개) / Status(상태 조회)
