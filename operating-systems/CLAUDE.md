# Claude 지침서

## 프로젝트 개요

이 저장소는 운영체제(Operating Systems) 학습 프로젝트입니다.
- 참고 도서: "운영체제: 아주 쉬운 세 가지 이야기" (OSTEP, Remzi & Andrea Arpaci-Dusseau)
- 선수과목: 자료구조, 컴퓨터 구조

## 대화 시작 시 해야 할 일

0. **상위 폴더(study/)의 CLAUDE.md를 먼저 읽고, 변경된 내용이 있는지 확인할 것**
   - 변경 사항이 있으면 이 파일에도 반영

1. **README.md를 읽어서 현재 진도를 파악할 것**
2. 체크리스트에서 완료되지 않은 첫 번째 항목을 확인
3. 사용자에게 다음 공부할 주제를 권유
4. 학습 일지의 마지막 날짜를 확인하여 얼마나 쉬었는지도 언급

## 학습 진행 방식 (상세)

### 1단계: 학습 목표 제시
### 2단계: 동기부여 (왜 OS가 이렇게 동작하는지)
### 3단계: 핵심 개념 설명 (다이어그램 활용!)
### 4단계: 예제/실습 (리눅스 명령어, 시스템 콜)
### 5단계: 연습 문제
### 6단계: 정리

### 퀴즈 원칙 (중요!)

- **모든 용어와 개념을 빠짐없이** 퀴즈로 다룰 것. 핵심만 추리지 말고 지엽적인 디테일까지 출제
- 챕터에 등장하는 **모든 용어, 정의, 숫자, 순서, 비교**를 암기 대상으로 삼을 것
- 교수님 시험이 매우 지엽적이므로, 사소해 보이는 것도 놓치지 않기
- 한 번 설명한 것으로 끝내지 말고, **퀴즈로 확인 → 틀리면 재시험 → 자력 정답 나올 때까지** 반복
- 다음 챕터로 넘어가기 전에 현재 챕터의 **모든 항목이 최소 2-practicing 이상**이어야 함

## 복습 시스템 (3단계 진행)

영어 학습 폴더와 동일한 패턴 사용:

```
review/
├── 1-new/terms.md       ← 새로 배운 용어/개념
├── 2-practicing/terms.md ← 복습 중 (1차 퀴즈 통과)
└── 3-mastered/terms.md   ← 완벽 암기 (2차 퀴즈 통과)
```

### 복습 프로세스

1. **매 수업 시작 시**: `1-new/terms.md`와 `2-practicing/terms.md`에서 랜덤 퀴즈 출제
   - 용어 → 정의, 정의 → 용어, 비교 문제, 빈칸 채우기 등 다양한 형식
   - 시험에 나올 만한 지엽적 디테일도 포함할 것
2. **퀴즈 결과에 따라 승급**:
   - 1-new에서 정답 → `2-practicing`으로 이동
   - 2-practicing에서 정답 → `3-mastered`로 이동
   - 오답 → 현재 단계에 유지
3. **사용자가 완벽히 암기했다고 판단되지 않으면**: 다음 챕터로 넘어가지 말고 추가 퀴즈 실시

### 용어 기록 형식

```markdown
## Ch.X 챕터제목

- **용어 (English Term)**: 정의. 핵심 디테일과 관련 개념 포함
```

## 학습 완료 후 할 일

- `review/1-new/terms.md`에 새로 배운 용어/개념 추가
- `notes/` 폴더에 학습 노트 작성
- README.md의 체크리스트 업데이트
- 학습 일지 테이블에 기록 추가
- **상위 study/ 폴더는 별도 git repo가 아니므로 커밋할 필요 없음.** 각 과목 폴더의 레포만 커밋 & 푸시하면 됨.

## 학습 마인드셋

OSTEP의 3가지 핵심 주제를 항상 기억하기:
- **가상화(Virtualization)**: CPU와 메모리를 가상화하여 각 프로세스에게 전용 자원이 있는 것처럼 보이게 함
- **동시성(Concurrency)**: 멀티스레드 프로그래밍에서 발생하는 문제를 이해하고 해결하기
- **영속성(Persistence)**: 파일 시스템과 I/O 장치를 통해 데이터를 안전하게 저장하기
- 실제 리눅스에서 직접 확인해보기
