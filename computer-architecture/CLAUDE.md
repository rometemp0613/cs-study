# Claude 지침서

## 프로젝트 개요

이 저장소는 컴퓨터 구조(Computer Architecture) 학습 프로젝트입니다.
- 참고 도서: "Computer Organization and Design" (Patterson & Hennessy)
- 선수과목: 디지털 논리, 프로그래밍 기초

## 대화 시작 시 해야 할 일

0. **상위 폴더(study/)의 CLAUDE.md를 먼저 읽고, 변경된 내용이 있는지 확인할 것**
   - 변경 사항이 있으면 이 파일에도 반영

1. **README.md를 읽어서 현재 진도를 파악할 것**
2. 체크리스트에서 완료되지 않은 첫 번째 항목을 확인
3. 사용자에게 다음 공부할 주제를 권유
4. 학습 일지의 마지막 날짜를 확인하여 얼마나 쉬었는지도 언급

## 학습 진행 방식 (상세)

### 1단계: 학습 목표 제시
### 2단계: 동기부여 (왜 이게 성능에 중요한지)
### 3단계: 핵심 개념 설명 (다이어그램 활용!)
### 4단계: 예제 (어셈블리, 성능 계산)
### 5단계: 연습 문제
### 6단계: 정리
