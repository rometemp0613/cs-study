- CS의 수학적 기초
- 참고 도서: "Discrete Mathematics and Its Applications" - Kenneth Rosen

## 학습 진행 방식 (상세)

사용자가 공부를 시작하면 **이 순서대로** 진행할 것:

### 1단계: 학습 목표 제시
- 이 주제에서 배울 핵심 내용 소개
- 끝나면 뭘 할 수 있게 되는지 설명

### 2단계: 동기부여
- 왜 이게 필요한지, CS에서 어디에 쓰이는지 설명
- 알고리즘, 자료구조, 암호학 등과의 연관성

### 3단계: 핵심 개념 설명
- 이론을 쉽게 풀어서 설명
- 수학적 증명은 직관적으로 먼저, 형식적으로 나중에

### 4단계: 예제 풀이
- 개념 적용 예제 제공
- 단계별로 풀이 과정 설명

### 5단계: 스스로 해보기
- 연습 문제 2-3개 제시
- 힌트는 요청하면 제공

### 6단계: 퀴즈
- 이해도 확인을 위한 간단한 퀴즈

### 7단계: 정리
- 오늘 배운 핵심 개념 요약
- 다음 주제 예고

## 복습 시스템 (3단계 진행)

```
review/
├── 1-new/terms.md       ← 새로 배운 용어/개념
├── 2-practicing/terms.md ← 복습 중 (1차 퀴즈 통과)
└── 3-mastered/terms.md   ← 완벽 암기 (2차 퀴즈 통과)
```

### 복습 프로세스

1. **매 수업 시작 시**: `1-new/terms.md`와 `2-practicing/terms.md`에서 랜덤 퀴즈 출제
2. **퀴즈 결과에 따라 승급**:
   - 1-new에서 정답 → `2-practicing`으로 이동
   - 2-practicing에서 정답 → `3-mastered`로 이동
   - 오답 → 현재 단계에 유지
3. **사용자가 완벽히 암기했다고 판단되지 않으면**: 다음 챕터로 넘어가지 말고 추가 퀴즈 실시
