# 이산수학 (Discrete Mathematics) 학습 기록

## 진도 체크리스트

### Part 1: 논리 (Logic)

- [ ] **명제 논리 기초**
  - 핵심: 명제, 논리 연산자 (∧, ∨, ¬, →, ↔)
- [ ] **명제의 동치**
  - 핵심: 드모르간 법칙, 항진식, 모순식
- [ ] **술어 논리**
  - 핵심: 전칭 한정자 (∀), 존재 한정자 (∃)
- [ ] **추론 규칙**
  - 핵심: Modus Ponens, Modus Tollens, 증명 기법

### Part 2: 증명 기법 (Proof Techniques)

- [ ] **직접 증명**
  - 핵심: P → Q를 직접 보이기
- [ ] **간접 증명**
  - 핵심: 대우 증명, 귀류법
- [ ] **수학적 귀납법**
  - 핵심: 기본 귀납법, 강한 귀납법
- [ ] **존재성/유일성 증명**
  - 핵심: 구성적 증명, 비구성적 증명

### Part 3: 집합론 (Set Theory)

- [ ] **집합의 기초**
  - 핵심: 원소, 부분집합, 멱집합, 합집합, 교집합
- [ ] **집합 연산**
  - 핵심: 차집합, 대칭차, 드모르간 법칙
- [ ] **곱집합과 함수**
  - 핵심: 카테시안 곱, 함수의 정의
- [ ] **함수의 성질**
  - 핵심: 단사, 전사, 전단사, 역함수

### Part 4: 관계 (Relations)

- [ ] **관계의 기초**
  - 핵심: 이항관계, 관계의 표현 (행렬, 그래프)
- [ ] **관계의 성질**
  - 핵심: 반사적, 대칭적, 추이적, 반대칭적
- [ ] **동치 관계**
  - 핵심: 동치류, 분할
- [ ] **순서 관계**
  - 핵심: 부분순서, 전순서, 하세 다이어그램

### Part 5: 조합론 (Combinatorics)

- [ ] **계수의 기초**
  - 핵심: 곱의 법칙, 합의 법칙
- [ ] **순열과 조합**
  - 핵심: P(n,r), C(n,r), 중복순열, 중복조합
- [ ] **이항정리**
  - 핵심: 이항계수, 파스칼 삼각형
- [ ] **비둘기집 원리**
  - 핵심: 비둘기집 원리, 일반화
- [ ] **포함-배제 원리**
  - 핵심: |A∪B| = |A| + |B| - |A∩B|

### Part 6: 점화식과 생성함수

- [ ] **점화식**
  - 핵심: 선형 점화식, 특성방정식
- [ ] **점화식 풀이**
  - 핵심: 동차/비동차, 피보나치
- [ ] **생성함수 기초**
  - 핵심: 일반 생성함수, 지수 생성함수

### Part 7: 그래프 이론 (Graph Theory)

- [ ] **그래프 기초**
  - 핵심: 정점, 간선, 차수, 경로, 사이클
- [ ] **그래프의 종류**
  - 핵심: 방향/무방향, 가중치, 이분 그래프
- [ ] **그래프 연결성**
  - 핵심: 연결요소, 단절점, 브릿지
- [ ] **오일러와 해밀턴**
  - 핵심: 오일러 경로/회로, 해밀턴 경로/회로
- [ ] **트리**
  - 핵심: 트리의 성질, 신장 트리
- [ ] **평면 그래프**
  - 핵심: 평면성, 오일러 공식, K₅, K₃,₃
- [ ] **그래프 색칠**
  - 핵심: 색칠수, 4색 정리

### Part 8: 정수론 기초

- [ ] **나눗셈 정리**
  - 핵심: 몫, 나머지, 정수 나눗셈
- [ ] **최대공약수**
  - 핵심: GCD, LCM, 유클리드 알고리즘
- [ ] **모듈러 연산**
  - 핵심: 합동, 모듈러 덧셈/곱셈
- [ ] **암호학 기초**
  - 핵심: RSA 개념, 페르마 소정리
