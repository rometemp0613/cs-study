# 새로 배운 용어/개념

## Part 1-1: 데이터베이스 시스템 개요

- **DBMS**: 데이터베이스를 생성·관리·조작하는 소프트웨어. 파일 시스템의 중복/불일치/종속 문제 해결
- **데이터 독립성**: 데이터 구조를 바꿔도 응용 프로그램에 영향을 주지 않는 것. "바뀐 놈 이름 = 독립성 이름"
- **논리적 독립성**: 개념 스키마가 바뀌어도 외부 스키마에 영향 없음 (논리적 사상이 보장)
- **물리적 독립성**: 내부 스키마가 바뀌어도 개념 스키마에 영향 없음 (물리적 사상이 보장)
- **3단계 스키마 (ANSI/SPARC)**: 외부(여러 개) → 개념(1개) → 내부(1개)
- **외부 스키마**: 사용자/응용 프로그램마다 필요한 부분만 보는 뷰
- **개념 스키마**: DB 전체의 논리적 구조, 딱 하나 존재, DBA가 관리
- **내부 스키마**: 물리적 저장 구조 (파일, 인덱스, 레코드 형식)
- **사상(Mapping)**: 스키마 간의 변환 규칙. 논리적 사상(외부↔개념), 물리적 사상(개념↔내부)

## Part 1-2: 관계형 데이터 모델

- **릴레이션(Relation)**: 2차원 테이블. E.F. Codd(1970)가 제안한 관계형 모델의 기본 단위
- **튜플(Tuple)**: 릴레이션의 행(Row). 하나의 레코드
- **속성(Attribute)**: 릴레이션의 컬럼(Column). 하나의 필드
- **도메인(Domain)**: 속성이 가질 수 있는 의미적으로 허용 가능한 값의 집합. SQL에서 CHECK 제약조건으로 구현
- **차수(Degree)**: 컬럼 수
- **카디널리티(Cardinality)**: 행 수
- **릴레이션 스키마**: 릴레이션의 구조 정의 (이름 + 속성 목록). 클래스에 비유
- **릴레이션 인스턴스**: 특정 시점의 실제 데이터 (튜플들의 집합). 객체에 비유
- **릴레이션 4특성 (유무무원)**: 튜플의 유일성, 튜플의 무순서, 속성의 무순서, 속성의 원자성
- **속성의 원자성**: 각 속성 값은 더 이상 쪼갤 수 없는 원자값이어야 함. 1NF(제1정규형)의 근거
