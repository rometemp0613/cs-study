## 주제: Part 1-1 데이터베이스 시스템 개요

첫 수업!

## 배운 내용

### 파일 시스템의 문제점
- 데이터 중복 → 불일치
- 프로그램-데이터 종속성
- 동시 접근 제어 불가
- 장애 복구 어려움

### DBMS (Database Management System)
- 데이터베이스를 생성·관리·조작하는 소프트웨어
- 주요 기능: DDL, DML, DCL, 동시성 제어, 장애 복구

### 데이터 독립성
> "바뀐 놈 이름 = 독립성 이름"

| 구분 | 의미 |
|------|------|
| 논리적 독립성 | 개념 스키마 변경 → 외부 스키마 영향 없음 |
| 물리적 독립성 | 내부 스키마 변경 → 개념 스키마 영향 없음 |

### 3단계 스키마 (ANSI/SPARC)
- 외부 스키마 (여러 개) ← 사용자별 뷰
- 개념 스키마 (1개) ← DB 전체 논리 구조
- 내부 스키마 (1개) ← 물리적 저장 구조
- 스키마 간 변환 = 사상(Mapping)
