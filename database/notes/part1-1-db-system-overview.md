# Part 1-1: 데이터베이스 시스템 개요

## 파일 시스템의 문제점
- 데이터 중복 → 불일치
- 프로그램-데이터 종속성
- 동시 접근 제어 불가
- 장애 복구 어려움

## DBMS (Database Management System)
데이터베이스를 생성·관리·조작하는 소프트웨어

주요 기능:
- DDL: 테이블 구조 정의
- DML: 삽입/수정/삭제/조회
- DCL: 권한, 보안, 무결성
- 동시성 제어, 장애 복구

## 데이터 독립성
> "바뀐 놈 이름 = 독립성 이름"

| 구분 | 의미 | 키워드 |
|------|------|--------|
| 논리적 독립성 | 개념 스키마 변경 → 외부 스키마 영향 없음 | 테이블 구조, 컬럼, 뷰 |
| 물리적 독립성 | 내부 스키마 변경 → 개념 스키마 영향 없음 | 인덱스, 파일, 디스크 |

## 3단계 스키마 (ANSI/SPARC)

```
외부 스키마 (여러 개) ← 사용자별 뷰
    ↕ 논리적 사상 → 논리적 독립성
개념 스키마 (1개) ← DB 전체 논리 구조, DBA 관리
    ↕ 물리적 사상 → 물리적 독립성
내부 스키마 (1개) ← 물리적 저장 구조
```
