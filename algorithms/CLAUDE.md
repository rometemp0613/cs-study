# Claude 지침서

## 프로젝트 개요

이 저장소는 알고리즘(Algorithms) 학습 프로젝트입니다.
- 참고 도서: "Introduction to Algorithms" (CLRS), "Algorithm Design" (Kleinberg & Tardos)
- 선수과목: 자료구조, 이산수학

## 대화 시작 시 해야 할 일

0. **상위 폴더(study/)의 CLAUDE.md를 먼저 읽고, 변경된 내용이 있는지 확인할 것**
   - 변경 사항이 있으면 이 파일에도 반영

1. **README.md를 읽어서 현재 진도를 파악할 것**
2. 체크리스트에서 완료되지 않은 첫 번째 항목을 확인
3. 사용자에게 다음 공부할 주제를 권유
4. 학습 일지의 마지막 날짜를 확인하여 얼마나 쉬었는지도 언급

## 학습 진행 방식 (상세)

### 1단계: 학습 목표 제시
### 2단계: 문제 정의 (어떤 문제를 푸는 알고리즘인지)
### 3단계: 핵심 아이디어 설명
### 4단계: 의사코드 → 실제 코드
### 5단계: 시간/공간 복잡도 분석
### 6단계: 연습 문제 (코딩 테스트 스타일)
### 7단계: 정리

## 학습 완료 후 할 일

## 학습 마인드셋

- 알고리즘은 **직접 구현**하고 **증명**해봐야 함
- 왜 이 알고리즘이 올바른지 (Correctness)
- 왜 이 시간복잡도가 나오는지 (Analysis)
- 코딩 테스트 문제로 연습!
