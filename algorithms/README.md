## 진도 체크리스트

### Part 1: 알고리즘 분석

- [ ] **점근적 분석**
  - 핵심: Big-O, Big-Ω, Big-Θ, 상한/하한
- [ ] **재귀와 점화식**
  - 핵심: 점화식 세우기, 마스터 정리
- [ ] **분할 상환 분석**
  - 핵심: 집합적 분석, 회계 방법, 잠재 방법

### Part 2: 정렬 알고리즘

- [ ] **기본 정렬**
  - 핵심: 버블, 선택, 삽입 정렬, O(n²)
- [ ] **병합 정렬 (Merge Sort)**
  - 핵심: 분할정복, O(n log n), 안정 정렬
- [ ] **퀵 정렬 (Quick Sort)**
  - 핵심: 피벗, 파티션, 평균 O(n log n)
- [ ] **힙 정렬 (Heap Sort)**
  - 핵심: 힙 구조, O(n log n), 제자리
- [ ] **선형 시간 정렬**
  - 핵심: 계수 정렬, 기수 정렬, 버킷 정렬
- [ ] **정렬의 하한**
  - 핵심: 비교 기반 정렬 Ω(n log n) 증명

### Part 3: 탐색 알고리즘

- [ ] **이진 탐색**
  - 핵심: O(log n), lower/upper bound
- [ ] **이진 탐색 응용**
  - 핵심: 파라메트릭 서치, 결정 문제

### Part 4: 분할 정복 (Divide and Conquer)

- [ ] **분할 정복 패턴**
  - 핵심: 분할 → 정복 → 결합
- [ ] **카라츠바 곱셈**
  - 핵심: 큰 수 곱셈, O(n^1.585)
- [ ] **가장 가까운 점 쌍**
  - 핵심: 2D 점, O(n log n)

### Part 5: 동적 프로그래밍 (DP)

- [ ] **DP 기초**
  - 핵심: 최적 부분 구조, 중복 부분 문제
- [ ] **1차원 DP**
  - 핵심: 피보나치, 계단 오르기, 동전 교환
- [ ] **2차원 DP**
  - 핵심: LCS, LIS, 배낭 문제
- [ ] **구간 DP**
  - 핵심: 행렬 체인 곱셈, 최적 BST
- [ ] **비트마스크 DP**
  - 핵심: 부분집합, 외판원 문제

### Part 6: 그리디 알고리즘

- [ ] **그리디 기초**
  - 핵심: 탐욕적 선택, 최적 부분 구조
- [ ] **활동 선택 문제**
  - 핵심: 구간 스케줄링
- [ ] **허프만 코딩**
  - 핵심: 최적 접두사 코드, 압축
- [ ] **그리디 vs DP**
  - 핵심: 언제 그리디가 최적인지

### Part 7: 그래프 알고리즘

- [ ] **BFS/DFS 응용**
  - 핵심: 연결 요소, 이분 그래프 판별, 사이클 탐지
- [ ] **최단 경로 - Dijkstra**
  - 핵심: 음이 아닌 가중치, O((V+E) log V)
- [ ] **최단 경로 - Bellman-Ford**
  - 핵심: 음수 가중치, 음수 사이클 탐지
- [ ] **모든 쌍 최단 경로**
  - 핵심: Floyd-Warshall, O(V³)
- [ ] **최소 신장 트리**
  - 핵심: Kruskal, Prim, Union-Find
- [ ] **강한 연결 요소 (SCC)**
  - 핵심: Kosaraju, Tarjan
- [ ] **네트워크 플로우**
  - 핵심: Ford-Fulkerson, 최대 유량

### Part 8: 문자열 알고리즘

- [ ] **문자열 매칭 기초**
  - 핵심: 브루트 포스, O(nm)
- [ ] **KMP 알고리즘**
  - 핵심: 실패 함수, O(n+m)
- [ ] **라빈-카프**
  - 핵심: 해시 기반, 롤링 해시
- [ ] **접미사 배열**
  - 핵심: 접미사 정렬, LCP 배열

### Part 9: 고급 주제

- [ ] **NP-완전성**
  - 핵심: P, NP, NP-완전, 다항 시간 환원
- [ ] **근사 알고리즘**
  - 핵심: 근사 비율, 정점 덮개, TSP
- [ ] **랜덤 알고리즘**
  - 핵심: Las Vegas, Monte Carlo
